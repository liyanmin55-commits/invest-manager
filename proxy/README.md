# 投资管家 · 行情代理（Cloudflare Worker）

零运维、免费的 serverless 函数，专门解决一件事：浏览器跨域拉不到股票/基金行情。
它**只收到代码，看不到你的账户、金额、持仓**——隐私始终留在你本机。

## 它做什么
- 收：`POST { "quotes": [ { "symbol": "600519", "asset": "股票" }, ... ] }`
- 回：`{ "600519": { "price": 1560.0, "name": "贵州茅台" }, ... }`
- 数据源：A股/ETF/可转债/黄金 → 东方财富；场外公募基金 → 天天基金

## 部署（只需一次）
你需要一个 Cloudflare 账号（免费）。在**自己电脑**的终端里：

```bash
# 1. 安装 wrangler（WorkBuddy 沙箱里装了也没用，必须在你真机）
npm install -g wrangler
# 2. 登录 Cloudflare（浏览器跳出来授权）
wrangler login
# 3. 进到本目录部署
cd 投资管理系统/proxy
wrangler deploy
```

部署成功会打印一个地址，类似：
```
https://invest-quote-proxy.<你的子域>.workers.dev
```

## 接进 App
1. 打开「投资管家」→ 设置 → 行情代理，粘贴上面地址，点「保存代理地址」。
2. 回到任意页，点顶部「刷新行情」。
3. 状态栏会提示「行情已更新 N 个标的」，净值/盈亏自动重算。

> 没部署也完全能用：设置里「手动行情」可以自己填每个标的的现价。

## 先验证能不能用（可选，真机执行）
```bash
cd 投资管理系统/proxy
node test.mjs
```
会真实请求几个样本（茅台、易方达蓝筹、沪深300ETF），打印拿到的价格。
能打印出数字 = 数据源契约没问题，放心部署。

## 说明
- 日级更新足够：你不是日内交易者，东方财富/天天基金给的报价算净值/盈亏已足够准。
- 港股：已做 best-effort（尝试 116./128. secid），如遇取不到可在 worker.js 的 `prefixes` 调整。
- 加密货币/房产/私募不在此列——它们没有标准公开行情源。
